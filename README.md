# pkguard Homebrew tap

Homebrew tap for [pkguard](https://pkguard.dev).

```bash
brew install jackmcpickle/pkguard/pkguard
```

That taps and trusts the formula. Homebrew 6 will not load a third-party tap until it is trusted, so this is the short path:

```bash
brew tap jackmcpickle/pkguard
brew trust jackmcpickle/pkguard
brew install pkguard
```
